# Padanan kata sederhana

Tabel ini buatan kami, bukan kamus ASD. Tabel ini memetakan kata yang terlalu sering dipakai dalam dokumen buatan AI ke pengganti yang sederhana. Jika kata itu tidak membawa fakta, hapus, jangan diganti.

| Hindari | Tulis |
|---|---|
| memanfaatkan, mendayagunakan, mengutilisasi | memakai |
| dalam rangka, guna | untuk |
| sebelum melakukan | sebelum |
| memastikan bahwa, memverifikasi, memvalidasi, mengonfirmasi | pastikan |
| perlu dicatat bahwa, patut diperhatikan bahwa | (hapus) |
| penting untuk | (hapus, lalu nyatakan faktanya) |
| cukup, hanya perlu, dengan mudah, secara mulus, tanpa hambatan | (hapus) |
| tangguh, andal, canggih, komprehensif, mumpuni | (hapus, atau sebut sifat yang terukur) |
| fungsionalitas | fungsi, fitur |
| memungkinkan Anda untuk | Anda dapat |
| dirancang untuk, bertujuan untuk | (hapus, lalu sebut apa yang dilakukannya) |
| memfasilitasi | membantu |
| menyelami, mendalami | membaca, memeriksa |
| ketika berbicara tentang, terkait dengan | untuk, tentang |
| apabila terjadi | jika |
| dikarenakan, disebabkan oleh fakta bahwa | karena |
| sesuai kebutuhan | (sebut syaratnya) |
| dan/atau | pilih satu, atau tulis "X, Y, atau keduanya" |
| dll., dsb. | (sebut butirnya) |
| langsung bisa dipakai, out of the box | secara default |
| di balik layar | secara internal |
| super cepat, kilat | cepat (beri angkanya) |
| menyederhanakan alur | membuat lebih sederhana, membuat lebih cepat |
| segudang, berbagai macam | banyak |
| krusial, sangat penting, vital, esensial | penting |
| sinergi, ekosistem (kiasan), lanskap (kiasan) | (hapus) |
| rumit dan kompleks | kompleks |
| revolusioner, inovatif, terdepan, mutakhir | baru (atau hapus) |
| mengubah permainan, transformatif | (hapus, lalu sebut apa yang berubah) |
| menonjolkan, menggarisbawahi, menekankan | menunjukkan |
| memberdayakan, mendorong | membantu |
| meningkatkan kualitas | memperbaiki |
| selain itu, lebih lanjut, di samping itu | juga |
| kesimpulannya, pada akhirnya, singkatnya | (hapus) |
| secara holistik, menyeluruh | lengkap |
| paradigma | model |
| membanggakan, memiliki keunggulan | punya |
| namun demikian, meskipun begitu | tetapi |
| semoga membantu, mari kita mulai | (hapus) |
